# Yaswanth Kumar Thota — Full-Stack Portfolio

- Frontend: HTML, CSS, JS
- Backend: Node.js + Express
- Database: MongoDB (stores projects and contact messages)
- Deployment: Render

## Setup
1. Create a free MongoDB Atlas cluster and get your connection string.
2. Deploy this repo on Render as a Web Service.
   - Build Command: npm install
   - Start Command: node server.js
   - Environment Variable: MONGODB_URI = your Atlas connection string
3. In Render's Shell tab, run: npm run seed
4. Visit your live Render URL — your portfolio is now live with a working backend and database.
